# LaraLiveUI Starter Kit

Official Laravel starter kit for LaraLiveUI — includes auth scaffolding (login, register, password reset, 2FA, profile), app layout with sidebar, and settings pages.

📚 **[Dokumentasi Lengkap →](https://elnasnato.github.io/laraliveui-docs/)**

## Install

```bash
laravel new app --using=elnasnato/laraliveui-starter-kit
```

## Requirements

- PHP ^8.3
- Laravel ^13.7
- Livewire ^4.1
- Tailwind CSS v4
